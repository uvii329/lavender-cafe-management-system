# Lavender Cafe Management System

## Overview
Lavender Cafe Management System is a desktop application developed using C# and SQL Server for managing café operations efficiently.

## Features

- User Authentication
- Role-Based Access Control
- Admin Dashboard
- Cashier Dashboard
- Product Management
- Customer Management
- Order Processing
- Profile Image Support
- SQL Server Database Integration

## Technologies Used

- C#
- Windows Forms
- SQL Server
- ADO.NET
- Visual Studio
